# Diona Internship Assignment

## Overview

This repository contains the frontend assignments completed as part of the Diona internship task.

The assignment focuses on recreating the provided PDF designs as closely as possible using HTML and CSS.

## Exercises

### Exercise 1

* Recreated the design provided in the assignment PDF.
* Implemented using HTML and CSS.
* Focused on matching the layout, spacing, typography, and overall appearance.

### Exercise 2

* Recreated the design provided in the assignment PDF.
* Implemented using HTML and CSS.
* Focused on maintaining visual consistency with the reference design.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the required exercise folder.
4. Open `index.html` using Live Server in VS Code.
